# DevForge Onboarding - Sistema de Pedidos da Cafeteria

Projeto prático desenvolvido durante a trilha de aprendizagem dos requisitos mínimos para estágio de Desenvolvedor Python e Java simulando uma onboarding de estagiários da **DevForge Studios**, empresa fictía que emite demandas ao aluno através do Google Gemini (Flash 3.8)

Código simulando a lógica de checkout e fechamento de pedidos de uma cafeteria local.

## Tecnologias
* Python
* Git/GitHub

## Regras de Negócio
* Cadastro de itens com nome, preço unitário e quantidade.
* Cálculo automatizado de subtotal por item e total do pedido.
* Aplicação de regras de desconto progressivo (10% e 15%).

## Como Executar
1. Certifique-se de ter o Python 3 instalado.
2. Clone ou acesse a pasta do repositório.
3. Execute o comando no terminal:
```bash
python main.py
```
